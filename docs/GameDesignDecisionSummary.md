작성일: 2026-06-05  
목적: 지금까지 대화와 구현 과정에서 정한 등급, 영웅 스킬, 아웃게임 성장, UI/사운드 방향, 밸런스 기준을 나중에 바로 확인할 수 있게 정리한다.

## 핵심 플레이 감각

초반에는 플레이어가 강하다는 느낌을 먼저 준다. 몬스터가 잘 맞아주고, 내가 조합한 유닛이 시원하게 이기는 감각이 중요하다.

중반부터는 몬스터 스킬 때문에 덱, 배치, 등급 성장, 아웃게임 성장이 필요해지는 구조로 간다. 단순히 수치만 높은 몬스터보다, 기절/마나 감소/도발 대응/광역 피해 같은 허들이 있어야 재미가 올라간다.

보스는 죽자마자 바로 결과창으로 넘기지 않고, 사망 피드백과 연출을 보여준 뒤 결과창으로 넘어가는 방향을 유지한다.

## 등급 체계

코드 enum 기준:

| 코드 | 표시명 | 비고 |
| --- | --- | --- |
| `Normal` | 일반 | 기본 등급 |
| `Rare` | 레어 | 초반 강화 등급 |
| `Epic` | 희귀 | 대화에서 말한 "희귀" 기준은 이 등급 |
| `Legendary` | 전설 | 중후반 안정 클리어 기준 |
| `Mythic` | 신화 | 상위 성장 등급 |
| `Transcendent` | 초월 | 최상위 조합/표시 등급 |

주의: UI 일부에는 `MythicCard`가 `초월`로 표시되는 흔적이 있다. 최종 서비스 전에 `신화`와 `초월` 표기 체계를 한 번 정리해야 한다.

영웅 번호는 오른쪽 기획표의 `프리팹이름 -> 변경된영웅번호` 기준으로 재배치한다. 등급은 나중에 업데이트로 영웅을 추가해도 번호만 보고 바로 알 수 있도록 장기 구간제로 관리한다. 이 매핑은 `CharacterDatabase`의 canonical hero grade override가 기준이며, 영웅 목록도 등급 순서로 정렬된다.

| 등급 | 영웅 |
| --- | --- |
| 일반 | `hero_01` ~ `hero_05` |
| 레어 | `hero_06` ~ `hero_10` |
| 희귀 | `hero_11` ~ `hero_20` |
| 전설 | `hero_21` ~ `hero_30` |
| 신화 | `hero_31` ~ `hero_50` |
| 초월 | `hero_51` ~ `hero_100` |

현재 구현된 영웅은 `hero_01~hero_14`, `hero_21~hero_23`, `hero_31~hero_33`, `hero_51~hero_57`이다. `hero_15~hero_20`, `hero_24~hero_30`, `hero_34~hero_50`, `hero_58~hero_100`은 이후 업데이트를 위해 예약된 빈 슬롯으로 둔다.

## 소환 스킬 결정

`hero_21`의 소환체는 `Dice_Pawn`을 사용한다. 소환체는 스킬을 사용할 때마다 필드에 임시로 나오며, 라운드 종료 시 사라져야 한다.

소환체는 현재 체력과 공격력의 20% 수준을 기준으로 한다. 이전 초안의 1/4보다 낮춘 이유는 필드에 추가 유닛이 생기는 구조라 전투 안정성이 크게 올라가기 때문이다.

소환체는 자기 자신과 같은 유닛이 아니라 `Dice_Pawn`으로 고정되어야 한다.

## 스킬/공격 애니메이션 이벤트 기준

기본 공격:

- 근거리 기본 공격: `AttackHit` 시점에 즉시 피해 적용
- 원거리 기본 공격: `FireProjectile` 시점에 투사체 발사, 투사체가 몬스터에게 맞는 타이밍에 피해 적용

스킬:

- 근거리/즉시 피해 스킬: `SkillHit` 또는 `SkillApply` 시점에 효과 적용
- 투사체 스킬: `SkillFire` 시점에 투사체 발사, 투사체 충돌 시 효과 적용
- 장판 스킬: `SpawnArea` 시점에 장판 생성
- 버프/힐/마나/도발 계열: `SkillApply` 권장
- 소환형 스킬: 현재 `SummonRush` 계열이며, 소환 타이밍을 명확히 하려면 `SkillApply` 또는 스킬 전용 이벤트로 맞추는 것이 좋다

## 아웃게임 성장/상점 기준

플레이 모드는 `Test`와 `Service`를 분리한다.

- 테스트 버전: 모든 캐릭터 사용 가능, 다이아 충전 가능
- 서비스 버전: 보유 영웅만 출전 가능
- 서비스 시작 영웅 수: 5명
- 현재 서비스 시작 영웅 후보: `hero_01`, `hero_02`, `hero_03`, `hero_04`, `hero_05`
- 시작 영웅은 일반 5종으로 잡는다. 첫 보스 전에는 레어 이상을 직접 뽑거나 합성해서 도달하는 것을 초반 목표로 둔다.

상점/뽑기:

- 상점은 인게임과 분리된 씬으로 연결한다.
- 다이아로 상자를 구매해 캐릭터 카드를 뽑는다.
- 명함 획득은 비교적 쉽게 한다.
- 높은 등급 카드는 낮은 확률로 획득한다.
- 1회 뽑기 기본 비용: 100 다이아
- 10회 뽑기 기본 비용: 900 다이아
- 서비스 시작 다이아: 1000
- 테스트 시작 다이아: 999999
- 테스트 다이아 충전량: 10000

현재 기본 뽑기 확률:

| 등급 | 확률 |
| --- | ---: |
| 일반 | 65.0% |
| 레어 | 23.0% |
| 희귀 | 8.5% |
| 전설 | 2.8% |
| 신화 | 0.6% |
| 초월 | 0.1% |

카드 성장:

- 최초 해금 필요 카드: 1장
- 레벨 2 필요 중복 카드: 2장
- 이후 레벨당 추가 필요 카드: +1장
- 최대 카드 레벨: 20
- 카드 레벨당 공격력 증가: +3%
- 카드 레벨당 최대 체력 증가: +3%

몬스터는 컬렉션 성장 평균에 따라 같이 스케일된다.

- 일반 몬스터 체력: 평균 성장 레벨당 +1.8%
- 일반 몬스터 공격력: 평균 성장 레벨당 +1.2%
- 보스 체력: 평균 성장 레벨당 +2.5%
- 보스 공격력: 평균 성장 레벨당 +1.6%
- 몬스터 체력 보너스 상한: +75%
- 몬스터 공격 보너스 상한: +50%

## 하루 플레이 시간 기준 밸런스

서비스 밸런스 기준은 하루 3시간 플레이하는 무과금 적극 플레이어로 잡는다.

단, 일일 필수 숙제는 20~40분 안에 끝나야 한다. 3시간은 필수 시간이 아니라, 더 플레이하면 성장과 도전이 계속 있는 기준으로 사용한다.

플레이어 구간:

| 유저 유형 | 하루 플레이 기준 |
| --- | --- |
| 일반 유저 | 30~60분 |
| 적극 유저 | 1~2시간 |
| 깊게 파는 유저/테스트 기준 | 3시간 |
| 무과금 1~2일 재미 보장 | 누적 3~6시간 |

보스 기준:

| 구간 | 목표 시간 | 요구 성장 기준 |
| --- | --- | --- |
| 보스 1 | Day 1 / 0~30분 | 희귀 1개면 클리어 흐름이 보임 |
| 보스 2 | Day 1 / 30~90분 | 희귀 1개 + 안정적 배치 |
| 보스 3 | Day 1 / 90~180분 | 희귀 2개 이상 또는 강한 레어 시너지 |
| 보스 4 | Day 2 시작 | 전설 준비가 중요해지기 시작 |
| 보스 5 | Day 2 | 전설 1개가 안정 클리어 기준 |
| 보스 6~7 | Day 2 이후 | 전설 중심 덱 또는 여러 희귀 성장 필요 |
| 보스 8+ | 장기 진행 | 덱 성장, 배치, 보스 스킬 대응 모두 필요 |

## 보스 스킬 피드백 기준

보스 스킬은 반드시 눈으로 읽혀야 한다.

- 스킬 준비 단계: 경고 링/배너
- 스킬 발동 단계: 보스 캐스팅 FX
- 피해/디버프 적용 단계: 타격 FX, 카메라 흔들림, 상태 표시
- 아군이 맞았을 때 표시: `기절`, `마나 -`, `처형` 등

보스 기본 FX는 `MonsterCombatTuningConfig.asset`에서 관리한다.

- 밝고 장난감 같은 3D 보드 위에 깊은 네이비 오버레이
- 둥글고 두꺼운 모바일 버튼
- 보상/전투/닫기/확인 버튼의 색을 강하게 구분
- 등급 표시와 체력바는 작게 숨기지 않고, 겹치지 않게 크게 읽히도록 배치
- 도감/상점/대전/결과창은 중앙 정렬과 텍스트 여백을 우선한다

참조 문서: `Docs/rollroll_dice_heroes_ui_reference.md`

## 사운드 결정

사용 결정:

- 기본 공격: `ingame_commondice_attack`
- 피격: `ingame_commondice_hit`
- 기본 공격/피격 사운드는 기존보다 약 30% 크게
- 인게임 전투 시작: `ingame_battle`
- 카운트다운 5,4,3,2,1: `ingame_countdown`
- 승리: `BGM_Ingame_victory`
- 승리 시점 추가 효과음: `mfx_ingame_matching`

승리 사운드는 결과창보다 늦게 들리지 않도록 1~1.5초 정도 빠르게 시작하는 방향을 유지한다.

## 현재 남은 미정/확인 필요

- `Mythic`과 `Transcendent`의 한국어 표기 최종 정리 필요
- 서비스 시작 5영웅이 실제 초반 튜토리얼/덱 구성에 가장 좋은지 플레이 테스트 필요
- 보스 1~3 기준은 실제 플레이 타임과 뽑기 획득량을 보며 계속 조정 필요
- 기존 일부 문서/코드 주석의 한글 인코딩이 깨져 보이는 부분은 추후 정리 필요

## 업데이트 규칙

밸런스 기준이 바뀌면 이 문서를 먼저 수정한다. 이후 실제 값은 아래 순서로 반영한다.

1. 기준 변경 내용을 이 문서에 기록한다.
2. 인스펙터 테이블 또는 config 값을 수정한다.
3. 빌드를 확인한다.
4. 플레이 테스트 결과를 이 문서의 밸런스 기준에 다시 반영한다.
